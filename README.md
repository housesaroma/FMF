# FMF Test — Landing Page

## Как открыть
- Локально: откройте файл [src/index.html](src/index.html) в браузере.
- Ассеты: папка [src/assets/images](src/assets/images) (ASCII-имена для удобных ссылок).

## Использование ИИ
- Сгенерирована структура HTML секций и семантика (header/hero/benefits/composition/faq) с быстрым выравниванием под макет.
- Автоматически составлены CSS-стили (grid, типографика, кнопки, карточки, аккордеон) и адаптивные брейкпоинты.
- Подготовлен скрипт интерактивности (мобильное меню и FAQ).

## Что автоматизировалось и почему
- Автогенерация сеток и повторяющихся карточек — сокращает время на ручную верстку.
- Формирование CSS переменных и базовой дизайн-системы — упрощает поддержку и корректировки.
- Генерация JS-логики для интерактивных блоков — исключает рутину.

## Интеграция в Bitrix
- Шаблон Bitrix удален из рабочей области. Могу быстро восстановить по запросу.

Минимальная инструкция (если шаблон восстановлен):
1. Скопируйте папку bitrix-template/fmf-test в /bitrix/templates/ проекта.
2. Подключите шаблон в админке Bitrix.
3. В нужной странице вставьте:

```php
<?php
require($_SERVER["DOCUMENT_ROOT"]."/bitrix/header.php");
$APPLICATION->SetTitle("Complex SW Суставы");
include $_SERVER["DOCUMENT_ROOT"]."/bitrix/templates/fmf-test/page-content.php";
require($_SERVER["DOCUMENT_ROOT"]."/bitrix/footer.php");
```

## Оптимизация
- Ленивая загрузка изображений (loading="lazy") для всех иллюстраций кроме первого экрана.
- Использование CSS-градиентов вместо тяжёлых фоновых изображений.
- Единый набор CSS-переменных и переиспользуемые компоненты для уменьшения CSS.
- Адаптивные сетки на CSS Grid без JS для ускорения отрисовки.
